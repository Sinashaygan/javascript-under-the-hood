## Section: What's With That Name?

### Summary

JavaScript's name originated as a marketing decision, not because the
language was a smaller version of Java.

Its early names were Mocha and LiveScript.

### Core Concepts

- JavaScript and Java are distinct languages.
- Similar C-style syntax does not imply identical semantics.
- JS is the common abbreviation for JavaScript.
- ECMAScript is the standard that defines the core language.
- Year-based edition names, such as ES2019, identify standard versions.
- Host APIs are not automatically part of ECMAScript.

### Frontend Takeaway

Do not infer JavaScript's behavior from familiar syntax or another
language's mental model. TypeScript and React do not replace the need
to understand JavaScript runtime semantics.
